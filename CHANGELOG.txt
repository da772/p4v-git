p4v-git changelog
==================

0.2.3
- Added an ImGui directory picker to Workspace Explorer for browsing and selecting a source folder.

0.2.2
- Changed shelf Submit with active files to open the Shelve-and-Submit flow so unshelved shelf changes are committed before merge.
- Allowed reshelve-before-submit to continue when the active files have no new content to commit.
- Fixed active-change multi-select Diff so all selected files open diffs instead of only the right-clicked file.

0.2.1
- Added a File History tab in File Changes with per-file history loaded from `git log --follow`.
- Added File History context actions from Workspace Explorer, active change lists, and committed shelf file lists.
- Added history row actions to update the working file to a selected version, open the GitHub commit page, and diff against the current working version.
- Added drag/drop between history rows to open a diff between two file versions.
- Fixed history diffs for older entries by preserving the historical path for each commit, including rename-aware history.
- Batched release build checks so changed `main` and open pull request heads are checked on a two-hour schedule instead of every update.
- Added README CI status details and a liability disclaimer.

0.2.0
- Added a README application screenshot.
- Expanded README prerequisites with required command-line tools, including `git` and `curl`.
- Documented Linux, Windows, and macOS build dependencies more explicitly.

0.1.28
- Added a Linux Clang/Ninja CMake preset with a parallel build preset.
- Kept refreshed Git status files in their assigned shelf instead of moving shelf-owned files back to Main.
- Fixed active and committed shelf multi-file restore/revert flows, including immediate UI cleanup after revert.
- Preserved NUL-separated Git status output on Unix process reads so `git status -z` parses correctly.
- Reduced unnecessary string and vector parameter copies in internal UI job, workspace state, and shelf service paths.

0.1.27
- Fixed the target branch `+` button layout so it stays visible and clickable beside the branch selector.
- Added reusable UI width helpers for constraining inline controls.

0.1.26
- Changed Dear ImGui layout persistence from `imgui.ini` in the working directory to `gui.ini` beside the executable.
- Added a `+` action next to the target branch selector for creating and selecting a new target branch.
- Blocked new target branch creation while unshelved local changes or checked-out active files are present.

0.1.25
- Restored remote branch discovery without exposing the `origin` HEAD pseudo-ref as a selectable branch.
- Checkout remote-only target branches by creating a local tracking branch automatically.
- Disabled target branch switching while there are unshelved local changes or checked-out active files.

0.1.24
- Changed shelf Submit with active files to open the shelf summary/description modal first.
- Added a chained shelf job that shelves active files, creates or updates the shelf link, then submits the shelf in one operation.
- Kept direct Submit available for shelves that already have committed shelf contents and no active files.

0.1.23
- Added native Windows caption hit testing for the custom title bar so drag and Snap behave like a normal window.
- Excluded the custom title-bar buttons from the native drag region so minimize, maximize, and close remain clickable.

0.1.22
- Fixed title-bar mouse capture by replacing the drag InvisibleButton with passive hit testing.
- Kept native window drag and double-click maximize/restore from fighting over the same click.

0.1.21
- Replaced title-bar double-click handling with a custom click-time/position detector.
- Increased the title-bar drag threshold so small movement between clicks does not steal maximize/restore.

0.1.20
- Added a Shelve modal for existing shelves with Summary and Description fields.
- Defaulted the Shelve summary to the previous hard-coded commit message, `Shelve files`.
- Passed the Shelve modal text into the shelf branch commit message.

0.1.19
- Fixed title-bar double-click maximize/restore by delaying native drag until the mouse actually moves.

0.1.18
- Reduced custom title-bar height and window-control size slightly.
- Improved title-bar double-click handling so maximize/restore does not also start a drag.

0.1.17
- Reduced custom title-bar height and circular window-control size.
- Made title-bar dragging easier by starting native drag from a normal click on the title-bar background.

0.1.16
- Removed duplicate in-panel title headers now that dock tabs provide panel names.
- Moved custom title-bar window controls to the right side.
- Enlarged title-bar controls and made the title bar DPI-aware.
- Versioned the dockspace ID so the content area uses the title-bar inset instead of stale full-height docking state.
- Switched Windows title-bar dragging to native caption dragging so Aero Snap and OS window docking work.

0.1.15
- Added a custom dark ImGui style so the app looks less like stock Dear ImGui.
- Removed native OS window decorations from the GLFW window.
- Added a custom ImGui title bar with Mac-style circular close, minimize, and maximize controls.
- Reserved title-bar space above the main dockspace and added custom window drag support.

0.1.14
- Reworked README features to emphasize Perforce-like workflows backed by Git.
- Removed the README Notes section so implementation details live in this changelog instead.

0.1.13
- Updated the project description to better explain the P4V-inspired Git workflow.
- Added the app icon to README.md.
- Moved accumulated implementation notes out of README.md into this versioned changelog.

0.1.12
- Added a hidden process runner for Windows so Git, curl, VS Code, and browser commands run without command windows popping up.
- Switched Git command execution and GitHub helper commands away from _popen on Windows.
- Routed URL opening through the hidden process runner.
- Created the GLFW window hidden, applied runtime icons, then showed it to avoid Windows capturing the default icon too early.
- Added *.aps to .gitignore for resource compiler cache files.

0.1.11
- Changed Git status refresh to use full untracked file expansion with `git status --porcelain=v1 -z -uall`.
- Fixed active changes for files inside newly added folders so they show as full repo-relative paths.
- Changed Windows builds to use the GUI subsystem with `mainCRTStartup`.
- Linked Shell32 for Windows icon extraction.

0.1.10
- Added blank-space click behavior to clear selected active-change files.
- Pruned selected active-change files when they are no longer active or checked out.
- Switched Git status parsing to NUL-delimited porcelain output.
- Improved Windows runtime icon assignment with Win32 big/small window and class icons.

0.1.9
- Added embedded runtime icon pixel data generated from icon.png.
- Applied runtime window icons through GLFW on platforms that support per-window icons.
- Added Windows shared icon resource IDs for C++ and resource files.

0.1.8
- Enabled MSVC multi-process compilation with /MP for the app and ImGui targets.
- Added a right-click Diff action for active changes.
- Opened file diffs in VS Code with `code --reuse-window --diff` without waiting on VS Code.
- Stored temporary diff files under `.git/p4v-git/diffs`.

0.1.7
- Added Windows executable icon embedding through icon.ico and a resource file.
- Added Linux desktop entry and hicolor icon installation using icon.png.
- Added macOS icon generation from icon.png into p4v-git.icns for app bundles.
- Added icon resources to the CMake/MSVC project structure.

0.1.6
- Added target branch persistence in workspace state.
- Made shelf branch naming target-aware with `shelves/<user>/<target>/<shelf>`.
- Moved shelf creation into the Active Changes context menu.
- Added active-change multi-select with Ctrl and Shift.
- Added multi-file drag/drop between shelves.
- Inserted newly created shelves into the UI immediately after creation.
- Added target branch selection in Workspace Explorer.
- Made submits target the selected branch instead of always using main.

0.1.5
- Added application versioning through CMake and generated P4vGitVersion.h.
- Updated merge-tool launching so VS Code is opened without blocking indefinitely.

0.1.4
- Added pull-before-submit workflow.
- Added pull status for the selected mainline branch.
- Added support for submitting local target-branch changes with summary and description.
- Improved shelf submit cleanup so submitted shelves are removed from the app and branch state.

0.1.3
- Added background Git operations so refreshes and shelf actions do not block the main UI thread.
- Added busy/disabled shelf UI states with spinners.
- Added slower auto-refresh and refresh deferral while Git mutations are running.
- Added focus-triggered refresh behavior.

0.1.2
- Added Git-backed shelf services for branch-backed shelves.
- Added GitHub pull request creation, shelf link lookup, submit/merge, and branch deletion.
- Added checked-out workspace state under `.git/p4v-git/state.json`.
- Added Workspace Explorer file checkout/revert context actions.
- Added File Changes shelf panels, shelf file lists, links, submit, shelve, delete, restore, and revert actions.
- Added auto-scrolling log behavior.

0.1.1
- Refactored the single-file prototype into Application, renderer, GUI, and UI layers.
- Added abstract renderer, GUI, and GLFW-facing interfaces.
- Added ImGui docking base and reusable UI widget wrappers.
- Added Workspace Explorer, File Changes, and Log dock panels.
- Added default dock placement for left, center, and bottom panels.
- Added MSVC source groups for project folders.

0.1.0
- Bootstrapped the cross-platform C++20 desktop app.
- Added CMake, Vulkan, GLFW, and Dear ImGui docking branch integration.
- Created a GLFW native window using Vulkan with FIFO present mode for VSync.
- Initialized Dear ImGui with docking enabled.
- Rendered the ImGui demo window.
